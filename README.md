# To Do App

A simple and functional to-do application built with HTML, CSS, and vanilla JavaScript.
Users can create tasks, edit them, delete them, mark them as complete, and filter
the task list by status. Tasks are also saved using localStorage so they remain
available after refreshing the page.

## Features
- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as complete or incomplete
- Filter tasks by status (All, Active, Completed)
- Tasks persist across page reloads using localStorage

## Built With
- HTML5
- CSS3
- JavaScript (vanilla, no frameworks or libraries)

## How to Run
1. Clone or download this repository
2. Open index.html in a web browser
3. No installation, dependencies, or build process is required

## What I Learned
This project helped me practice building an interactive application using
plain JavaScript. I learned how to manage application data with arrays and
objects, respond to user actions, update the DOM, work with localStorage,
and keep the interface synchronized with the current state of the task list.
